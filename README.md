# Future Bloom

Create a better version of https://ecovion.in/ with only frontend no backend. I want to add a blog page also a page where all future product are showcased.


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
